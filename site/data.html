Data sources and credits

Earwitness comes with no data. When an analysis needs it, the app downloads public data straight from each source to your computer, and keeps it in a local folder.

If you share something made with these sources, such as a map or a screenshot of results, keep the credit notices below with it.

What it doesn't use

  • Blitzortung and LightningMaps. Their terms don't allow third-party apps to pull their data. Earwitness never contacts them.
  • OpenSky Network. Its historical data is limited to researchers and licensees.
  • MET Norway lightning. Planned for later; v0.1 covers the Americas only.
  • Paid lightning networks (Vaisala, Earth Networks). Not included.

Using the map tiles fairly

The app's map uses OpenStreetMap's free tile servers, which volunteers run for light use. The desktop window identifies itself to them, and the app loads only the tiles you look at. If you need heavy use, set another tile server in the app's Setup page.

Software credits

The app is built on open-source software, including NumPy, SciPy, rasterio and GDAL, xarray, h5py, PyArrow, Shapely, FastAPI, pywebview, MapLibre GL JS and Plotly.js. Their licences ship with the app: the Windows build includes a THIRD_PARTY_LICENSES folder, and the app's footer links the licences of its map and chart libraries.

The method

The method comes from colsto's videos: thunder with Blitzortung data, thunder with MET Norway data, and propeller-aircraft Doppler. His code is not public. Earwitness is an independent reconstruction from the videos, using only sources whose terms allow it.
