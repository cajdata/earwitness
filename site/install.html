Install

Earwitness runs on 64-bit Windows 10 or 11 and on Linux. Everything runs on your computer.

Windows build

  1. Download earwitness-0.1.0-windows-x64.zip and its .sha256 file from the latest release.
  2. Open PowerShell in your Downloads folder. Check the download: the two values must match. 
    (Get-FileHash .\earwitness-0.1.0-windows-x64.zip -Algorithm SHA256).Hash
Get-Content .\earwitness-0.1.0-windows-x64.zip.sha256
  3. Unblock and extract it: 
    Unblock-File .\earwitness-0.1.0-windows-x64.zip
Expand-Archive .\earwitness-0.1.0-windows-x64.zip -DestinationPath $env:USERPROFILE\Earwitness
  4. Run the check. It should end with demo passed: 
    cd $env:USERPROFILE\Earwitness\earwitness-0.1.0-windows-x64
.\earwitness.exe demo
  5. Double-click earwitness-ui.exe in that folder to open the app. The two demo runs are on its Results page.

If Windows warns you

The build isn't code-signed, so if you skip Unblock-File, Windows may show "Windows protected your PC". Click More info, then Run anyway. If you'd rather not, install with pipx instead.

The app window needs Microsoft Edge WebView2, which Windows 11 includes. Without it, the app opens in your web browser and shows a small box to stop it.

With pipx or uv (Windows or Linux)

pipx install earwitness
earwitness demo

With uv instead: uv tool install earwitness. Either way you get two commands: earwitness for the command line, and earwitness-ui for the app.

On Linux

  • On Debian or Ubuntu, get pipx with sudo apt install pipx, then pipx ensurepath.
  • earwitness ui --browser opens the app in your web browser on any desktop.
  • For an app window, add a toolkit: pipx inject earwitness "pywebview[qt]".
  • Minimal systems without the expat library need sudo apt install libexpat1; the demo's install check tells you if so.

Optional: ffmpeg

With ffmpeg installed, Earwitness can read video and compressed audio (MP4, MOV, M4A, MP3 and more) and check a file's metadata. Without it, WAV, FLAC and OGG still work.

  • Windows: winget install --id Gyan.FFmpeg -e
  • Debian or Ubuntu: sudo apt install ffmpeg

Disk space

The app itself takes about 350 MB. The public data it downloads takes more, and stays in a data folder until you delete it: about 100 MB per hour of lightning data, about 4 GB to download per day of flight data, and about 40 MB per terrain tile. Set EARWITNESS_CACHE to keep it on another drive.

Uninstall

  • Windows build: delete the folder, and any runs and data folders Earwitness made.
  • pipx: pipx uninstall earwitness. uv: uv tool uninstall earwitness.
